# E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes an e-commerce dataset to understand sales performance, product-level performance, costs, profitability, and order trends.

The project demonstrates an end-to-end data analytics workflow using SQL, Python, Pandas, and Power BI.

## 🎯 Business Objectives

The analysis focuses on answering questions such as:

- How are sales and orders performing?
- Which products contribute most to revenue and profit?
- How do product prices and costs affect profitability?
- What are the major trends in customer orders?
- Which areas of the dataset require data cleaning?
- How can the analysis be presented through an interactive dashboard?

## 🛠️ Tools & Technologies

- **SQL / MySQL** – Data querying and business analysis
- **Python** – Data analysis and processing
- **Pandas** – Data cleaning and transformation
- **Matplotlib** – Data visualization
- **Power BI** – Interactive dashboard and reporting
- **Jupyter Notebook** – Analysis workflow
