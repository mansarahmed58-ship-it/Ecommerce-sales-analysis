# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce dataset to understand sales performance, product performance, customer behavior, profitability, and revenue trends.

The project demonstrates an end-to-end data analytics workflow using SQL, Python, Pandas, and Power BI.

## Business Objectives

The analysis answers key business questions:

- How are sales, orders, and profit performing?
- Which products generate the highest revenue and profit?
- Which products have the highest profit margins?
- How does revenue change over time?
- What is the contribution of one-time and repeat customers?
- How do customer types differ in revenue and profit?
- How can the analysis be presented through an interactive dashboard?

## Tools & Technologies

- SQL / MySQL – Data analysis and business queries
- Python – Data analysis
- Pandas – Data cleaning and transformation
- Power BI – Dashboard development and visualization
- GitHub – Project documentation and version control

## Project Workflow

1. Data preparation and cleaning using Python and Pandas
2. Business analysis using SQL
3. Creation of calculated metrics
4. Development of Power BI dashboards
5. Analysis of product and customer performance
6. Documentation of findings and insights

## Key Analysis

### Overall Business Performance

The dashboard tracks:

- Profit
- Profit Margin
- Orders
- Customers
- Units Sold
- Monthly Revenue Trend

### Product Analysis

The analysis evaluates:

- Revenue by product
- Profit by product
- Profit Margin by product
- Top products by revenue
- Top products by profit

### Customer Analysis

The analysis evaluates:

- One-time vs repeat customers
- Revenue by customer type
- Profit by customer type

## Key Findings

- Total revenue is approximately **$2.63M**.
- Total profit is approximately **$1.66M**.
- Overall profit margin is approximately **63.11%**.
- The dataset contains approximately **32.3K orders** and **31.7K customers**.
- Product 1 contributes the largest share of revenue and profit.
- Repeat customers represent a much smaller share of customers than one-time customers.
- Revenue shows a general upward trend over the analyzed period, with fluctuations toward the end.

### Customer Analysis
